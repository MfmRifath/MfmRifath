## `> cat ./ai-tuition-master/ARCHITECTURE`

<div align="center">

<img src="https://raw.githubusercontent.com/MfmRifath/MfmRifath/main/assets/pipeline.svg" width="100%" alt="AI Tuition Master architecture — student, LangGraph router, hybrid retriever, QLoRA-tuned Llama 3, groundedness check, Bayesian knowledge tracing feedback loop" />

</div>

An intelligent tutoring system for Tamil-medium A/L Physics. **Why it is not just a chatbot:**
answers are refused or re-retrieved when the groundedness check fails, and the next question
is chosen from a live mastery estimate rather than a fixed syllabus order.
